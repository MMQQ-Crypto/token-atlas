# Token Atlas 网页真实用量采集

1. 启动 Token Atlas 桌面应用，在“数据来源”中点击“启动网页采集”。
2. 在 Edge / Chrome 的扩展管理页面开启“开发人员模式”，点击“加载解压缩的扩展”，选择本文件夹。
3. 点击扩展图标，填写桌面端显示的采集地址，粘贴桌面端复制的配对码，勾选启用并保存。
4. 刷新已打开的聊天网页，之后正常使用。

只解析 Fetch / XMLHttpRequest 响应中的标准 `usage` 对象（含 JSON 和 SSE）。没有服务端用量字段、使用加密或非标准私有协议、通过 WebSocket 返回的数据不会生成 Token 数。不使用字数估算，不获取隐藏的推理或缓存数量，不读取历史浏览器记录。

匹配范围为 manifest 中列出的国内官方聊天网站。适配表示可观察这些页面的标准响应，不保证各站点都会返回真实用量；扩展面板会显示观察到的响应数量和实际含 usage 的数量。官网改版或在非匹配域名使用时可能无法采集。

页面响应在本机解析，传给桌面端的只有响应标识、模型、Token 数、来源域名和时间。对话正文、Cookie、API Key 不会发送到桌面端，也不会持久保存。断线时暂存最多 1000 条用量元数据，连接恢复后重试。关闭页面或响应尚未结束时可能来不及获取最终 usage。

配对码只用于连接本机桌面采集服务，不是平台 API Key。桌面应用重启后配对码会变化，需要重新粘贴。关闭采集开关后不会继续读取新响应。

扩展已用隔离的 JSON / SSE 响应样例验证；各个已登录官网的响应格式仍取决于平台实际提供的数据，未声明已验证全部官网。
