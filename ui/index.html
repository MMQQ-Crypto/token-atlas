采集真实用量

网页采集未启动

DeepSeek Harness 的本地压缩日志会自动读取。其他国内网页可通过扩展采集响应中的 usage；已有网络响应记录可直接导入。

如何连接网页采集
  1. 点击“启动网页采集”，再点击“打开扩展文件夹”。
  2. 打开 Edge 或 Chrome 的扩展管理页面，开启“开发人员模式”，选择“加载解压缩的扩展”，加载该文件夹。
  3. 打开扩展，填入上方地址，粘贴配对码，勾选启用并连接。每次重启桌面应用需重新配对。
  4. 刷新国内 AI 聊天网页后正常使用。只记录服务端明确返回的 usage，不保存对话正文；扩展会显示多少响应含有真实用量。

只支持可读取的 Fetch / XHR JSON 或 SSE 响应。隐藏用量、加密响应和 WebSocket 无法还原，未获得的数据不会计数。导入 HAR 时，使用浏览器开发者工具“网络”面板保存带响应正文的 HAR 文件；原始 HAR 可能包含敏感信息，请只保存在本机，不要对外发送。

国内 AI 真实用量

只统计服务端 usage

汇总本地桌面日志、网页响应采集与导入记录中的真实 Token。DeepSeek Harness 的调用可自动统计，包括日志中的豆包等模型。网页只有返回明确 usage 时才会计数。

厂商按模型名称或响应所属的官方网页识别，不代表实际付费平台。没有记录表示尚未采集到数据，不表示没有使用；不估算隐藏推理、上下文长度或账单额度。

自动刷新

每 60 秒读取更新的本地记录，应用打开时生效。新采集的网页记录会即时刷新。

应用不修改原始日志，不上传本地记录。来自多个通道的同一次调用可能重复，分析时可按工具筛选。网页和导入记录按响应标识去重；Cookie、密钥和聊天正文不会保存到采集记录。
