自动发现应用

读取本机受支持的应用数据目录，每分钟刷新。累计用量以保留的记录为准；另一台电脑的历史需要导入。

添加已有记录

若应用使用了自定义目录，或要读取另一台电脑拷贝来的日志，选择对应应用和记录文件夹。WorkBuddy 请选择 projects 记录目录；ZCode 请选择包含 db.sqlite 的目录。

读取另一台电脑的 WorkBuddy 记录
  1. 在使用 WorkBuddy 的电脑上运行本应用，可自动读取该电脑保留的会话用量。
  2. 如需汇总到这台电脑，将另一台的用户目录下 .workbuddy/projects（或 .workbuddy-ai/projects）复制到本机文件夹。
  3. 在上方选择 WorkBuddy，再选择复制后的记录目录。包含真实 usage 的调用才会计入；重复记录会去重。

本机扫描不会自动跨电脑同步。这里统计真实 Token，不将其换算为 WorkBuddy 积分或账号剩余额度。

网页与响应记录

网页采集未启动

本地 Agent 日志会自动读取。网页可通过扩展采集实际返回的用量字段，也可导入已有 JSON / JSONL / HAR 响应。

如何连接网页采集
  1. 启动网页采集，并打开扩展文件夹。
  2. 在 Edge / Chrome 的扩展管理页开启开发人员模式，加载解压缩的扩展。
  3. 在扩展中填写上方地址、粘贴配对码，启用并连接。
  4. 刷新聊天网页后正常使用。只记录实际返回的 usage 或完整 usageMetadata。

缺少用量、加密响应或 WebSocket 无法还原 Token。导入 HAR 时保存带响应正文的文件，仅在本机导入。

本机应用统计与平台账号总量范围不同。其他电脑、清理掉的日志、尚未接入的应用会影响覆盖范围。供应商按模型或响应来源识别；来自不同通道的相同调用可能重复，可通过应用筛选核对。原始日志不修改，聊天正文和认证信息不写入用量存储。
